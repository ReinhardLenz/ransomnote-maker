# Description


A hundred years ago, in cases of blackmail, criminals would send messages to their victims by cutting out various words and letters from newspapers (since handwriting or a typewriter was not possible, as it would have been a giveaway) and pasting them together to obscure the sender's identity. This small Python program does something similar. Each letter of the document gets its own font and size, randomly arranged, by a small pyhton program, that takes a docx document, and changes randomly the font type and size for each character.
